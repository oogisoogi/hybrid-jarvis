# 04 · 워커 프로토콜 — 스폰·브리프·검수 사이클

## 스폰 — 단일 입구

워커 기동은 스크립트 하나(`scripts/spawn-worker.sh`)로만 합니다. 손 기동(`cys launch-agent` 직접 호출 등)을 병행하면 모델 정책·역할 부여·각성 주입이 사람 기억에 의존하게 되고, 반드시 빠뜨립니다.

스폰 입구가 강제하는 것:

1. **모델 정본** — 프로젝트별 `.claude/spawn-model` 파일이 모델을 지정합니다. "이 티켓은 어떤 모델로"를 매번 사람이 정하지 않습니다.
2. **역할·cwd** — cwd는 "특성이 드러나는 폴더"로 고릅니다. 페인 제목의 뒷부분이 cwd에서 오므로, 이것이 곧 사람이 화면에서 워커를 알아보는 손잡이입니다.
3. **페인 제목** — 「번호 + 역할 한 단어」. master는 워커를 언급할 때 항상 이 조합으로 부릅니다(번호만 말하면 오너가 화면과 대조하지 못합니다).
4. **각성 주입** — 워커 공통 지침(WORKER DIRECTIVE)을 읽게 한 뒤 브리프를 전달합니다.

## 브리프 — 필수 칸 3개

작업 브리프는 프로젝트 폴더의 `.briefs/`에 파일로 남기고, 다음 세 칸은 **비어 있으면 안 됩니다**(없으면 "없음"이라고 적습니다 — 빈칸은 안 적은 것과 구분되지 않습니다).

### ① 이월(캐리오버)
직전 라운드·전임 워커에서 넘어온 상태·미결·함정. 에이전트는 자신이 했던 일을 기억할 때 최고 성과를 냅니다. 재발주·순환 후 재브리프에서 이 칸이 비면 맥락 유실 사고가 납니다.

### ② 비가역·비용 결정 목록
이 티켓 범위에서 예상되는 되돌리기 어려운 결정(배포·마이그레이션·삭제·외부 계정·과금·스키마 정의)을 열거하고, 각각 「워커 실행 금지 · master/오너 게이트」를 표기합니다. 인프라 결정은 사람이 합니다.

### ③ 상한·중단 조건
지시에 상한이 없으면 워커는 끝까지 갑니다 — 비동기라 비용은 이미 지출된 뒤에 발견됩니다(4만 회 재시도 루프 실사고). 시간 상한·시도 횟수 상한·막히면 보고 조건을 명시합니다.

## 발주 전 실측 2건

- **워커 CTX 실측** — 컨텍스트 60%를 넘긴 워커에게 새 티켓을 얹지 않습니다(60% = 워커 정지선). 발주 직전에 관측값을 한 줄 확인합니다.
- **노드 재활용 판정** — cwd가 같으면 `/clear` 후 재활용, 다르면 새 노드. 페인을 닫기 전에는 담긴 작업·대기 맥락을 실측로 확인합니다.

## 검수 사이클 — 3자 구도

완료 보고를 그대로 믿지 않습니다. 정본 구도:

```
워커 구현·자체검증 → 이종 검증자(다른 계열 LLM)의 적대검증 → master 독립 재실행
```

- **워커 자체검증**은 필요조건일 뿐입니다. 만든 자가 평가하면(producer = evaluator) 같은 맹점을 공유합니다.
- **이종 검증**은 다른 모델 계열에게 "반박하라"로 시킵니다. 단 외부 LLM의 판정만으로 수렴 선언은 불가 — 최종 판정은 master가 합니다.
- **master 독립 재실행** — 테스트 스위트·게이트 스크립트를 master가 자기 손으로 다시 돌립니다. "워커가 통과했다고 보고했다"와 "내가 돌려서 통과했다"는 다른 문장입니다.

배포·원격 DB 변경·마이그레이션은 검수 통과 후에도 **master 게이트**입니다(워커가 직접 하지 않습니다).

## 폐역과 갈무리

- 티켓 종결 시 워커의 산출물·미결·교훈을 SOT에 수납한 뒤 폐역합니다.
- 갈무리 없이 페인만 닫으면 다음 복원 때 "결손"으로 오인됩니다. 의도된 갈무리는 SOT에 의도를 남깁니다(durable 갈무리 — 2번 문서).
- 죽은 워커가 자동 부활 장치로 되살아난 경우, **절반 이상은 맥락이 없습니다.** 화면상 구별이 안 되므로, 부활 장치의 저널에서 `verified`(세션 일치)인지 `fresh`(맥락 없음)인지 읽고, fresh면 빈 워커로 취급해 처음부터 브리핑합니다.

## 워커 지시의 어조

워커에게 기대하는 문장은 "될 것입니다"가 아니라 "확인했습니다"입니다. 완료 보고에는 실측 증거(명령·출력·커밋 해시)를 요구하고, 검증 없는 자기보고는 반려합니다. 이것은 워커의 문제가 아니라 발주자의 서식 문제입니다 — 증거를 요구하는 칸이 브리프에 있어야 합니다.
